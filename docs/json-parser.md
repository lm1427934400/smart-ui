# JSON在线解析器使用说明

## 功能特性

1. **实时解析与验证**
   - 输入框支持实时监听（防抖处理，延迟500ms）
   - 自动校验JSON格式并高亮显示语法错误
   - 安全解析机制，避免使用eval()

2. **可视化树形结构**
   - 将JSON转换为可折叠的树形组件
   - 区分对象{}、数组[]、基础类型（字符串、数字、布尔值）的图标和颜色
   - 支持展开/折叠全部节点

3. **数据格式转换与编辑**
   - 一键格式化（缩进2/4空格）、压缩（去除空格）
   - 数据类型统计：显示对象深度、键值对总数、各类型数量分布

4. **附加工具集成**
   - JSON Schema生成：根据JSON结构自动生成Schema模板
   - 严格模式切换：支持标准JSON和JSON5格式

## 界面布局

采用三栏响应式布局：
- **左侧面板**：JSON输入编辑区
- **中间面板**：树形可视化展示
- **右侧面板**：详细信息面板

## 使用方法

1. 在左侧输入框中输入或粘贴JSON数据
2. 系统会自动进行解析和验证（500ms防抖）
3. 解析成功后，中间面板会显示树形结构
4. 右侧面板显示统计信息和生成的JSON Schema
5. 可以使用顶部工具按钮进行格式化、压缩等操作

## 技术实现

- 使用Vue 2 + Element UI组件库
- 树形组件采用自定义递归组件实现
- 解析核心使用原生JSON.parse()，确保安全性
- 错误捕获使用try-catch封装
- 支持大型JSON文件的性能优化处理
