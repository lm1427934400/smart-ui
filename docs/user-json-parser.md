# JSON在线解析器用户指南

## 功能介绍

JSON在线解析器是一个强大的工具，用于实时解析、验证和可视化JSON数据。它可以帮助开发者和数据分析师快速查看和理解复杂的JSON结构。

## 界面布局

解析器界面分为三个主要区域：

1. **左侧输入区**：用于输入或粘贴JSON数据
2. **中间可视化区**：以树形结构展示JSON数据
3. **右侧信息区**：显示详细统计信息和工具

## 基本使用

### 1. 输入JSON数据

在左侧文本框中输入或粘贴JSON数据。系统会自动在500毫秒后进行解析。

### 2. 查看解析结果

解析成功后，中间区域会显示JSON的树形结构：
- 对象用 `{}` 表示
- 数组用 `[]` 表示
- 基础类型（字符串、数字、布尔值、null）直接显示值

### 3. 展开/折叠节点

点击节点前的箭头图标可以展开或折叠该节点及其子节点。

### 4. 查看统计信息

右侧信息区显示：
- 对象深度
- 键值对总数
- 各数据类型的数量分布

## 工具功能

### 格式化

点击"格式化"按钮可以将压缩的JSON数据格式化为易读的格式。

### 压缩

点击"压缩"按钮可以去除JSON中的所有空格和换行符。

### 展开全部

点击"展开全部"按钮可以展开树形结构中的所有节点。

### 折叠全部

点击"折叠全部"按钮可以折叠树形结构中的所有节点。

### 清空

点击"清空"按钮可以清除所有输入和解析结果。

### 生成示例数据

点击"生成示例数据"按钮可以填充一个示例JSON结构，方便测试功能。

### 复制Schema

在右侧信息区可以查看自动生成的JSON Schema，并点击"复制Schema"按钮将其复制到剪贴板。

## 错误处理

如果输入的JSON格式不正确，系统会显示具体的错误信息，包括：
- 错误类型
- 错误位置（行号和列号）

## 高级功能

### 严格模式

默认开启严格模式，只接受标准JSON格式。可以点击"关闭严格模式"按钮来支持JSON5格式（允许注释、单引号等）。

### 数据类型统计

右侧信息区会统计各种数据类型的数量：
- 字符串
- 数字
- 布尔值
- 数组
- 对象
- Null值

### JSON Schema生成

系统会根据输入的JSON结构自动生成对应的JSON Schema，方便API设计和数据验证。

## 使用技巧

1. **大数据处理**：对于大型JSON文件，建议先压缩再粘贴，以提高处理速度
2. **错误定位**：当JSON格式错误时，仔细查看错误信息中的位置提示
3. **快速查看**：使用展开/折叠功能可以快速浏览复杂的数据结构
4. **格式转换**：在格式化和压缩功能之间切换可以满足不同的查看需求

## 常见问题

### 1. 为什么我的JSON无法解析？

请检查以下几点：
- 是否使用了双引号而不是单引号
- 是否有多余的逗号
- 是否有未闭合的括号
- 是否有非法字符

### 2. 如何查看大型JSON文件的特定部分？

使用树形结构的展开/折叠功能，可以逐步深入查看感兴趣的部分。

### 3. 如何保存解析结果？

目前系统支持将生成的JSON Schema复制到剪贴板，后续版本将支持更多导出功能。
